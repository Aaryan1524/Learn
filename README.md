# A History of AI

An open learning website sharing the history, mathematics, and ideas behind AI. Start with Part 1: Foundations, 1943–1959, with a 1936 computation prelude.

The application lives in [`ai-history/`](ai-history/). [`Reference.md`](Reference.md) is the master teaching and product specification.

```sh
cd ai-history
npm ci
npm run dev
```

From the repository root, `npm run dev`, `npm run build`, `npm test`, and `npm run typecheck` forward to the application. See the [application README](ai-history/README.md), [progress record](ai-history/docs/PROGRESS.md), and [visualization handoff](ai-history/docs/visualizations.md).

Eight lessons cover the origins of AI through training a perceptron in plain Python. The site includes guided practice, 16 checked checkpoint tasks, source companions, a glossary, and local progress. Twenty-nine named visual spaces are reserved for later images, diagrams, and interactive figures. Later parts remain planned.
